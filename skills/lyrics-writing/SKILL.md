# Writing lyrics

## Shape first, words second

A song is a shape before it is a sentence. Decide the shape, then fill it:

```
VERSE    sets the scene, low energy, one idea
PRE      turns the screw — the question the chorus answers
CHORUS   the one line he'd want repeated; the emotional thesis
VERSE    deepens, doesn't repeat verse one
CHORUS   same words, or escalate one line
BRIDGE   the turn — new angle, new key, or a confession
CHORUS   final, usually with the line that changes meaning
```

**Never write a second verse that restates the first.** If it doesn't add, cut it.

## The chorus is a promise

- **One idea, short lines, easy vowels.** If a line is hard to sing, it's the wrong line.
- **The title usually lives in it**, often on the first or last line.
- **Repeat the hook exactly.** A chorus that varies slightly each time reads as unfinished.

## Genre voices

| style | what it needs |
|---|---|
| **J-rock / anime rock** | a rising pre-chorus, a release on the vowel, English/Japanese mixing that feels natural rather than translated |
| **Post-hardcore / metalcore** | a scream line that still parses as words, a clean melodic answer underneath |
| **Ballad** | one image, held. Fewer words, longer notes |
| **Industrial / hip-hop hybrid** | hard consonants, short bars, a hook that lands like a stamp |
| **J-pop hopeful** | forward motion, a lift on the last line, no irony |

## Mixing Japanese and English

**Both languages must sound intentional in their own right.** A common failure is English that reads
like a translation of Japanese, or Japanese that exists only to signal genre.

- Put the emotional peak in whichever language carries it better for that line
- **Kanji is written correctly, or not used.** No approximated characters
- Romaji only as a reading aid beside real kana/kanji — never as a substitute
- Titles keep their own script: 弦の血, 四時, ジェンテック

## Editing pass — do this every time

1. **Read aloud.** Every line. Anything you stumble on gets rewritten.
2. **Count syllables in the chorus.** They should be consistent line to line.
3. **Hunt clichés** — "breaking free," "in the end," "never again," "rise up." Replace with something
   only this song could say.
4. **Check the rhyme is doing work.** A rhyme that forces a bad word is worse than no rhyme.
5. **Cut the last line of each verse.** It's usually the one explaining what the previous lines showed.

## What not to do

- Don't overwrite his intent. If he gives you a line, it stays — you fix the meter around it.
- Don't add a bridge because songs have bridges. Add one because the song needs a turn.
- Don't pad. A four-line verse that lands beats eight lines that circle.
